     Add On-Screen UI to Mandelbrot Viewer

     Context

     The Mandelbrot SFML viewer currently has no on-screen UI — drawUI() only
     updates the window title bar. Users have no visual guidance on controls, no
     way to see coordinates without reading the title bar, and no clickable
     preset buttons. This change adds overlay panels for information display,
     preset selection, and help.

     Plan

     1. Add UI state and font to renderer_sfml.h

     - Add sf::Font uiFont member and bool fontLoaded flag
     - Add UI state: bool showHelp, bool showInfo (both default true)
     - Add preset data structure and storage: struct PresetInfo { string name; 
       double real, imag, dist; int maxIter; }
     - Add preset selection callback: std::function<void(int)> onPresetSelected
     - Add setPresets() and setPresetSelectedCallback() methods
     - Add std::string computeMode and double lastComputeTimeMs for display
     - Add setComputeInfo(const std::string& mode, double timeMs) method

     2. Implement UI drawing in renderer_sfml.cpp

     - Load font in init() — try C:/Windows/Fonts/consola.ttf then
       C:/Windows/Fonts/arial.ttf then C:/Windows/Fonts/segoeui.ttf
     - Implement drawUI() with three panels:
       - Info panel (top-left, semi-transparent dark bg): center coordinates,
         zoom level, max iterations, compute mode, last compute time
       - Preset panel (top-right, semi-transparent dark bg): list of preset
         names as clickable buttons, highlight on hover
       - Help bar (bottom, semi-transparent dark bg): one-line control summary
         (drag=pan, scroll=zoom, 1-6=presets, H=help, I=info, Esc=quit)
     - All panels drawn with sf::RectangleShape backgrounds and sf::Text

     3. Add keyboard and click handling in renderer_sfml.cpp

     - In handleEvents(), add key handlers:
       - H toggles help bar visibility
       - I toggles info panel visibility
       - 1-6 (or however many presets) selects a preset via callback
       - R resets to full set (preset 1)
     - Add click detection on preset buttons in handleMousePress() — check if
       click is within preset button bounds before starting a drag

     4. Wire up in main.cpp

     - After renderer.init(), call renderer.setPresets(presets) to pass preset
       data
     - Set preset callback: renderer.setPresetSelectedCallback([this](int idx) {
       selectPreset(idx); })
     - After each compute(), call renderer.setComputeInfo(useGPU ? "GPU (CUDA)" 
       : "CPU", durationMs)

     Files to modify

     - renderer_sfml.h — new members, methods, struct
     - renderer_sfml.cpp — font loading, UI drawing, event handling
     - main.cpp — wire presets and compute info to renderer

     Verification

     - Build with build.ps1
     - Run the app and visually confirm:
       - Info panel appears top-left with coordinates and zoom
       - Preset buttons appear top-right, clicking one navigates there
       - Help bar at bottom shows controls
       - H/I keys toggle panels
       - Number keys select presets
       - Panels don't interfere with pan/zoom interaction
